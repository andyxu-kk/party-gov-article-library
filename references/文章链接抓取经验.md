# 文章链接抓取实战经验

> 本文件记录使用本 Skill 处理「用户只提供文章链接」时的抓取经验，供后续执行参考。

## 一、人民日报老站（paper.people.com.cn）

### 典型链接形态

```
https://paper.people.com.cn/rmrb/pc/content/YYYY/MM/DD/content_XXXXX.html
```

### 关键经验

1. **正文是动态/容器包裹的**：`web_fetch` 往往只能拿到 `<title>`（标题），正文正文在页面 HTML 的 `<div class="article">`（或 `article-box`、`ozoom`）容器里，需自行抓取 HTML 并解析。
2. **编码是 UTF-8**：不要猜 GBK！用 UTF-8 解码 `DownloadData` 拿到的原始字节。
   - PowerShell：`[System.Text.Encoding]::UTF8.GetString($bytes)`
   - 若用 GBK 解码会出现「锟斤拷」式乱码（`鈥滃績涓` 这种是 UTF-8 被 GBK 读的典型特征）。
3. **正文提取**：正则匹配 `<div[^>]*class="[^"]*article[^"]*"[^>]*>(.*?)</div>\s*</div>`（Singleline 模式），再从中提取所有 `<p>` 段落，去 HTML 标签 + `HtmlDecode` 转义。
4. **页面无独立小标题**：评论员观察等评论体裁往往没有小标题，正文以「心中有数，就要摸清实情」「手中有策，事就能干到点子上」等标志句自然分节，分析小标题体系时应说明这一体例特点。
5. **文末信息**：正文末尾常带「（本系列评论到此结束）」「——推进基层工作方法谈⑥」等系列信息，以及报纸版次（《 人民日报 》( 2026年08月19日 05 版)），注意提取用于 Front Matter 的来源/日期。

### PowerShell 抓取模板（参考）

```powershell
$wc = New-Object System.Net.WebClient
$bytes = $wc.DownloadData($url)
$html = [System.Text.Encoding]::UTF8.GetString($bytes)
$m = [regex]::Match($html, '<div[^>]*class="[^"]*article[^"]*"[^>]*>(.*?)</div>\s*</div>', 'Singleline')
$ps = [regex]::Matches($m.Groups[1].Value, '<p[^>]*>(.*?)</p>', 'Singleline')
# 每个 p 去标签 + HtmlDecode 即得正文段落
```

## 二、通用经验

- **优先官方源**：人民日报官网原文优先，其次是人民网观点频道（opinion.people.com.cn）等权威转载。
- **web_fetch 失败/不完整时的备选**：直接抓 HTML 解析；若仍失败，可先用搜索引擎定位同文转载页（人民网各频道常转发同文）。
- **多源核对**：标题、日期、版次以官方页面为准；搜索结果片段只能作线索，不能当全文。
- **正文不完整时**：不得依据标题或摘要猜测全文，应告知用户提供正文或换源重试。
